# 🌐 Django Translator App

A simple yet powerful **language translator web application** built with **Django**, **HTML**, and **CSS**, leveraging the **Google Translate API** for accurate and real-time translations.

---

## 🚀 Features

- 🌍 Translate text between multiple languages  
- ⚡ Real-time translation using Google Translate API  
- 🧠 Automatic language detection  
- 💻 Clean and responsive UI using pure HTML & CSS  
- 🧩 Easy to use and lightweight Django architecture  

---

## 🛠️ Tech Stack

- **Backend:** Django  
- **Frontend:** HTML, CSS  
- **API:** Google Translate API
